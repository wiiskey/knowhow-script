# 후킹 의도 10분류 + 노하우텔링 변환

> 영상 첫 1~2초 멘트를 "무엇을 건드리는가"로 나눈 작업 기준. 문장 예시는 이 스킬이 직접 만든 **빈칸 패턴**이며, 매번 주제의 구체 명사로 새로 쓴다.
> 패턴 코드: `의도번호-알파벳` (예: ⑦-b). 결과물의 `패턴` 열에 적는다.

## 한눈에

| # | 의도 | 건드리는 것 | 잘 맞는 목표 |
|---|------|-----------|------------|
| ① | 강한 자극 | 손해·긴장감 — "지금 안 보면 놓친다" | 조회·도달 |
| ② | 공감 | "내 얘기다" — 상황·감정 호명 | 공감·팔로우 |
| ③ | 숫자·비교 | 구체성 — 수치·전후·A/B | 저장·신뢰 |
| ④ | 유머·반전 | 예상 비틀기 — 비유·과장된 대조 | 조회·도달 |
| ⑤ | 감정·스토리 | 사건의 한 장면 — "그날" | 공감·팔로우 |
| ⑥ | 경험·신뢰 | 화자의 자격 — 직접 해본 것 | 신뢰·구매 |
| ⑦ | 실수 지적 | 불안 — "나도 그러고 있나?" | 신뢰·행동 |
| ⑧ | 방법 공개 | 즉시 쓸모 — 단계·순서 | 저장·행동 |
| ⑨ | 통념 깨기 | 인지 부조화 — 믿던 것이 틀림 | 조회·도달 |
| ⑩ | 정보·학습 | 이해 욕구 — 개념·구조 정리 | 저장 |

## 의도별 카드

### ① 강한 자극
- **원리**: 시청자가 잃을 것을 먼저 보여준다. 이득보다 손실이 더 빨리 멈추게 한다.
- **패턴**
  - ①-a `{대상}이 {결과}를 놓치는 지점, {장면}에서 갈려요`
  - ①-b `{행동} 전에 이것부터 확인하세요`
  - ①-c `{상황}이면 지금 {손실}이 생기고 있어요`
- **주의**: 공포를 부풀리지 않는다. 손실은 실제로 일어나는 것만.

### ② 공감
- **원리**: 시청자의 상황이나 속마음을 그대로 말해 "나를 부른다"고 느끼게 한다.
- **패턴**
  - ②-a `{상황}인데 {기대와 다른 결과}였던 분들`
  - ②-b `"{시청자 속마음 한 줄}" 이런 생각 드셨죠`
  - ②-c `{상황}, 혼자만 겪는 거 아니에요`
- **주의**: "당신" 대신 조건절로 부른다(rules.md G7).

### ③ 숫자·비교
- **원리**: 막연한 약속 대신 확인할 수 있는 수치·전후를 보여준다.
- **패턴**
  - ③-a `{전 수치}에서 {후 수치}로, 바꾼 건 {하나}`
  - ③-b `{A}랑 {B}, 실제로 비교해봤어요`
  - ③-c `{항목} {N}개 중 {M}개가 {결과}였어요`
- **주의**: 수치는 증거 목록에 있는 것만(G1). 없으면 ③을 쓰지 않는다.

### ④ 유머·반전
- **원리**: 예상 밖의 비유·대조로 웃거나 "응?" 하게 만든다.
- **패턴**
  - ④-a `{행동}은 {엉뚱한 비유}랑 같아요`
  - ④-b `{기대}하고 {행동}했는데 결과는 {반대}`
  - ④-c `{유행하는 말}, 진지하게 따져보면요`
- **주의**: 무거운 주제(건강·돈·이별·외모 콤플렉스)에는 쓰지 않는다.

### ⑤ 감정·스토리
- **원리**: 설명이 아니라 사건의 한 장면으로 시작해 "그래서?"를 부른다.
- **패턴**
  - ⑤-a `{시점}, {구체 장면}에서 처음 알았어요`
  - ⑤-b `{실수}하던 제가 {하나}를 바꾸고 달라진 것`
  - ⑤-c `{사람}이 한 말 한마디 때문에 {행동}을 바꿨어요`
- **주의**: 실제 있었던 일만. 지어낸 장면·인물 금지.

### ⑥ 경험·신뢰
- **원리**: 화자가 직접 해봤거나 많이 봤다는 사실이 신뢰를 만든다.
- **패턴**
  - ⑥-a `{실제 경력·건수} 해보고 남은 기준 하나`
  - ⑥-b `직접 {행동}해보니 {예상과 다른 점}`
  - ⑥-c `{검증 가능한 자료}에서도 같은 얘기를 해요`
- **주의**: 경력·건수·사례는 사실일 때만(G3).

### ⑦ 실수 지적
- **원리**: 흔한 실수를 짚어 "나도?"라는 불안으로 끝까지 보게 한다.
- **패턴**
  - ⑦-a `{행동}부터 하면 순서가 거꾸로예요`
  - ⑦-b `{결과}가 안 나오는 분들, 공통으로 {실수}하고 있어요`
  - ⑦-c `저도 {실수} 때문에 {손해} 본 적 있어요`
- **주의**: 사람을 탓하지 않고 행동을 짚는다.

### ⑧ 방법 공개
- **원리**: 바로 따라 할 수 있는 단계를 약속해 저장을 부른다.
- **패턴**
  - ⑧-a `{문제}일 때 제가 쓰는 {N}단계`
  - ⑧-b `{도구}, 이 설정 하나만 바꾸세요`
  - ⑧-c `{결과}까지 순서대로 보여드릴게요`
- **주의**: 약속한 단계 수는 본문에서 꼭 지킨다.

### ⑨ 통념 깨기
- **원리**: 모두가 믿는 것을 뒤집어 "왜?"를 만든다.
- **패턴**
  - ⑨-a `{통념}, 실제로는 반대로 작동해요`
  - ⑨-b `저도 {통념} 믿었는데 해보니 {다른 결과}`
  - ⑨-c `{흔한 조언}이 오히려 {손해}를 만드는 경우`
- **주의**: 뒤집는 근거가 본문에 있어야 한다. 근거 없는 반대는 낚시가 된다.

### ⑩ 정보·학습
- **원리**: 헷갈리는 개념을 정리해 준다는 약속으로 이해 욕구를 건드린다.
- **패턴**
  - ⑩-a `{개념}, 한 문장으로 정리하면요`
  - ⑩-b `{주제} 처음이면 {N}가지만 먼저 잡으세요`
  - ⑩-c `{A}랑 {B}, 차이는 {기준} 하나예요`
- **주의**: 약속한 "한 문장·N가지"를 실제로 지킨다.

## 클로저 (저장 유도)
- `{상황}일 때 다시 꺼내 보세요` · `{N}단계, 저장해두고 따라 해보세요` — 영상 끝 1문장. 첫마디와 같은 말을 반복하지 않는다.

## 노하우텔링 변환 3요소

정보성 문장을 노하우텔링 후킹으로 바꿀 때 아래 셋을 손본다. 후킹에는 **그 정보를 얻기까지 치른 값**이 보여야 한다.

| 손볼 것 | 정보성 (고치기 전) | 노하우텔링 (고친 뒤) |
|---|---|---|
| ① 주체 세우기 | "~하는 방법", "~ 3가지" (주어 없음) | "제가 ~해 보니", "저는 ~했어요" (1인칭 경험자) |
| ② 결과 대신 치른 값 | 성공 공식만 제시 | 실패·걸린 기간·버린 횟수·잃은 돈을 앞에 |
| ③ 구체 좌표 넣기 | 어디서나 통하는 일반론 | 구체 시간·장소·감정 (예: 새벽 5시, 2년 만에, 집들이 날) |

**바꿔 쓰기 예시** (구조 참고용 — 숫자는 실제 경험으로 바꾼다)
- 정보성 (뷰티): `내 피부에 맞는 파운데이션 고르는 법`
  → ① `제가 파운데이션 고르다 실패한 이유, 바르는 위치였어요`
  → ② `[N]개를 사고 [N]개를 서랍에 넣고 나서야 알았어요`
  → ③ `친구 결혼식 사진에서 제 얼굴만 둥둥 떠 있더라고요`
- 정보성 (패션): `키 작은 사람 바지 고르는 팁`
  → ① `키 158인 제가 바지 핏 하나로 달라 보인 방법`
  → ② `[N]년 동안 와이드 팬츠만 사고 매번 반품했어요`
  → ③ `면접 날 거울 앞에서 바지만 세 번 갈아입었어요`
- 정보성 (운동): `홈트 오래 하는 법`
  → ② `운동 기구 [N]개 샀다가 다 중고로 팔았어요`
  → ⑨형 `의지가 약한 줄 알았는데, 시간대 문제였어요`

**의도와 짝이 잘 맞는 변환**
- ⑤ 감정·스토리 + ③ 구체 좌표 → 장면으로 여는 첫마디
- ⑥ 경험·신뢰 + ① 주체 세우기 → "직접 해보니"형
- ⑦ 실수 지적 + ② 치른 값 → "저도 이것 때문에 손해 봤어요"형
- ⑨ 통념 깨기 + ② 치른 값 → "저도 믿었는데 해보니 반대였어요"형
